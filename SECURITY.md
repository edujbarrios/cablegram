# Security Policy

## Reporting a vulnerability

Do not report suspected vulnerabilities in a public issue, discussion, or pull
request.

Use GitHub's private vulnerability reporting feature for this repository:

1. Open the repository's **Security** tab.
2. Select **Advisories**.
3. Select **Report a vulnerability**.

If private vulnerability reporting is not available, ask the maintainers in a
public issue to enable or provide a private reporting channel. Do not include
vulnerability details in that issue.

Include the affected component or document, reproduction steps, impact, and any
suggested mitigation. Remove secrets and personal data from reports.

Maintainers should acknowledge a private report, investigate it, coordinate a
fix and disclosure where warranted, and credit the reporter if requested. No
specific response or remediation timeline is promised at this early stage.

## Supported versions

Cablegram has not published a release. Security support applies to the current
default branch only. This policy will be updated when versioned releases exist.
